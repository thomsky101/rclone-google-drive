Rclone Google Drive Backup

Personal Google Drive Backup Application

About This Application

This is a personal backup application used to securely synchronise files between a privately operated Linux server and the owner's Google Drive account.

How It Works

The application uses Rclone and Google's OAuth 2.0 authentication system to access the owner's Google Drive account.

Files are synchronised automatically as part of a scheduled backup process. The application is not offered as a public service.

Privacy and Security

Google Drive access is used only for the owner's personal backup operations. No Google user data is sold or shared with third parties.
