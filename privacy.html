Privacy Policy

Rclone Google Drive Backup

Overview

Rclone Google Drive Backup is a personal application used to back up files between a privately operated Linux server and the owner's Google Drive account. It is not offered as a public service.

Information Accessed

The application uses Google's OAuth 2.0 authentication system to obtain authorised access to the owner's Google Drive files.

How Information Is Used

Google Drive access is used only to perform the owner's personal backup and synchronisation operations.

Information Sharing

The application does not sell or share Google Drive user information with third parties. Files are transferred between the owner's Linux server and Google Drive.

Data Storage and Security

Authentication credentials are stored locally on the owner's Linux server and are not published on this website. Access to the server is restricted.

Data Retention and Deletion

Backed-up files remain in Google Drive or on the owner's server until they are removed through the owner's backup and file management procedures. Google Drive access can be revoked through the owner's Google Account settings.
